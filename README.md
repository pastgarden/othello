# 4人オセロ

4人で遊べるオセロ風のWebゲームです。

通常のオセロとは違い、  
4色の石を使って複数人で遊べるようにした作品です。

## サイト

https://pastgarden.github.io/othello/

## 内容

- 4人で遊べるオセロ風ゲーム
- 4色の石を使った盤面
- ブラウザ上で石を置いて遊べる
- スコアの集計はアナログで行う仕様

## この作品について

HTML / CSS / JavaScript の練習として作った、  
4人用のオセロ風Webゲームです。

本格的な自動判定ゲームというより、  
友達同士で盤面を使って遊ぶためのシンプルな作品です。

石の数は自動で数えず、  
最後にプレイヤー同士で確認して数えるアナログ方式です。

## 使用技術

- HTML
- CSS
- JavaScript
- GitHub Pages

## メモ

当時はまず「4人でオセロっぽく遊べる盤面」を作ることを優先していたため、  
スコアの自動集計機能は入れていません。

石の数は最後にプレイヤー同士で確認する、  
アナログ方式のシンプルな仕様です。
